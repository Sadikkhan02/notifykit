# @notifykit/adapter-twilio

## 1.0.0

### Major Changes

- Initial v1.0.0 production release of Twilio SMS adapter for NotifyKit.
  - SMS dispatch via Twilio REST API
  - Support for `from` phone numbers and Messaging Service SID
  - Twilio error code mapping into retryable and permanent failures
  - Account SID and Auth Token sanitization
